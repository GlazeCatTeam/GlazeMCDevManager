## Glaze MC Dev Manager v0.1.1

### 新增与改进

- AI 助手支持后台上传指定的本地素材，新建作品默认仅保存，也可在明确授权后创建并提交审核。
- AI 操作记录支持确认后清空，改善日志间距。
- 改善玩家评论评分筛选时的分批加载与结果保留。
- 优化趋势图悬浮数值和汇总表的自适应布局。

### 修复

- 修复作品细分类查找错误，统一新建、编辑保存与界面的分类选项。
- 修复标签建议框遮挡和残留问题，支持自动收起、键盘选择及窄窗口显示。
- 修复 AI 授权、单次授权消费、操作归档与重连中的问题，提高操作与重试的可靠性。

### 安装与更新

- Windows 10/11 x64：下载 `GlazeMCDevManager-0.1.1-x64-setup.exe`。
- 已安装用户可在「设置 → 关于」检查更新，下载后重启安装。
- 安装包暂未进行代码签名；如遇 Windows 提示，请核对下载来源为本仓库的 GitHub Releases。
- 攻略上传与编辑仍暂不支持。
