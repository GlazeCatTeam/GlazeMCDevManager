## Glaze MC Dev Manager v0.1.3

### 修复与改进

- 修复作品视频和封面提示保存成功却未实际替换的问题；保存后重新读取并核对视频，未生效时明确提示。
- 修复新建和编辑作品时标签未保存的问题，完善付费模组的视频与封面校验。
- 修复详情图片提交的兼容性问题，保留编辑器中的图片预览。
- 显示平台返回的具体资料校验原因，便于定位填写问题。
- 作品列表、归档和详情根据平台详情补全弱下架标记及原因，刷新后同步最新状态。
- 数据分析查询期间隐藏旧结果，避免将旧数据误认为新查询结果。

### 安装与更新

- Windows 10/11 x64：下载 `GlazeMCDevManager-0.1.3-x64-setup.exe`。
- 已安装用户可在「设置 → 关于」检查更新，下载后重启安装。
- 安装包暂未进行代码签名；请核对下载来源为团队仓库 `GlazeCatTeam/GlazeMCDevManager` 的 GitHub Releases。
- 攻略上传与编辑仍暂不支持。
