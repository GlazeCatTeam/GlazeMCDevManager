## Glaze MC Dev Manager v0.1.0（首个公开测试版）

网易我的世界开发者管理工具，Windows 10/11 x64。

### 能做什么

- **账号**：通过网易官方登录窗口或 Cookie 登录，多账号切换，登录过期后重新登录；登录信息只保存在本机并加密。
- **首页**：等级与经验、收益和下载概览、本月收益速算、四个排行榜。
- **作品管理**：作品列表、审核反馈、上架 / 定时上架 / 自测 / 调价 / 删除等操作，作品详情编辑与提交审核，直达该作品的数据分析。
- **数据分析**：日度追踪、月度汇总、模组分析、周期收益、实时收益。
- **收益管理**：PE / PC 月度收益与单笔详情（只读）。
- **玩家反馈、玩家评论、系统消息**：筛选、查看与回复。
- **活动推广**：作品活动、折扣特卖、PE 首页轮播图申请。
- **AI 助手**：一键连接 Claude Code、Codex、Cursor 等 AI 工具，按「只看数据 / 帮我打理 / 完全托管」三档授权，让 AI 帮你查数据、回复玩家、整理作品。
- **设置**：Ore UI 与 Fluent 主题、深浅色、界面缩放、开机自启、关闭到托盘、插件与日志。
- **自动更新**：之后的新版本会在后台下载，重启应用即可完成安装，也可以在 设置 → 关于 里手动检查。

### 安装须知

- 下载 `GlazeMCDevManager-0.1.0-x64-setup.exe` 并运行。
- 安装包**暂未进行代码签名**，Windows 可能提示「Windows 已保护你的电脑」。点击「更多信息」→「仍要运行」即可继续安装。
- 默认安装到当前用户目录，安装时可以更改位置；卸载在 Windows「设置 → 应用」中进行。

### 已知限制

- 攻略上传与编辑暂不支持。
- 活动推广和部分作品写操作还没有在真实平台上逐项验收，提交前请留意页面上的确认信息；如遇问题请到 [Issues](https://github.com/TheCoffeeCat-A/GlazeMCDevManager/issues) 反馈。
- 仅支持 Windows 10/11 x64。

### 许可

原创代码与文档采用 Apache-2.0；第三方依赖与资源声明可在 设置 → 关于 → 开源许可 中离线查看。本项目参考 [MCDevManager](https://github.com/BitterLemonn/MCDevManager) 的功能与接口行为，不包含其源码。
