## Glaze MC Dev Manager v0.1.2

### 新增与改进

- 作品支持本地归档与恢复，归档后从日常列表中收起，也可通过 AI 工具管理；归档不会删除平台上的作品。
- 系统消息有未读内容时，侧边栏显示红点；阅读后同步刷新，切换账号时分别显示。
- 实时收益新增近 7 天、近 30 天和自定义日期范围；模组分析支持自定义日历周期，数据汇总支持自选月份。
- 玩家评论新增屏蔽无文字评论筛选，改善筛选加载、结果保留和阅读位置。
- 优化作品列表切页、返回后的状态恢复与预加载体验。
- 首页收益和下载概览增加钻石及下载图标。

### 修复

- 修复自定义日期范围打开时的预选内容，完善月度汇总查询和月份切换交互。
- 完善作品归档与 AI 操作的状态同步、账号隔离及持久化处理。

### 安装与更新

- Windows 10/11 x64：下载 `GlazeMCDevManager-0.1.2-x64-setup.exe`。
- 项目仓库已恢复为团队仓库 `GlazeCatTeam/GlazeMCDevManager`，后续版本继续从此处发布；已安装用户仍可在「设置 → 关于」检查更新，下载后重启安装。
- 安装包暂未进行代码签名；如遇 Windows 提示，请核对下载来源为本仓库的 GitHub Releases。
- 攻略上传与编辑仍暂不支持。
