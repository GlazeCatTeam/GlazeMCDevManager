# ADR-0012 MCP 覆盖作品创建、更新与提交审核

- 状态：已实现本地服务与审批流程；真实平台写入验收待完成，见 [MCP 实装](../architecture/22-mcp-runtime.md)
- 日期：2026-10-16
- 关联：扩展 ADR-0008；实施细节见 [13 能力层与 MCP 接入](../architecture/13-mcp.md)

## 背景

用户要求 AI 能更新作品、提交审核，并填写和修改作品提交页面的内容。仅完成只读 MCP 无法满足这次接入目标。现有作品界面已经有创建、字段编辑、上传、保存和提审适配，但仍是 Shell 专用入口。

## 决定

复用现有业务服务，增加有结构化契约的 MCP 编辑能力，覆盖当前作品页面可编辑内容。通过隔离草稿、材料 ID、差异预览和应用内确认完成写入；保存与提审是独立步骤，可由用户一次明确批准“保存并提交审核”的固定操作序列。提审每次必须确认。

新增材料需经原生选择器或用户明确授权的素材目录导入，上传授权与目录读取授权分离。AI 不获得网易凭据，不能自行批准操作。缺少可靠平台协议的攻略编辑/上传等仍明确标记不支持。

## 后果

开发可以先打通只读链路，但本轮完成标准包含作品编辑与提审。需要新增草稿修订、材料管理、确认请求和持久化操作结果，并验证冲突、未知写结果和重试行为。既有平台无原子并发保护、创建不保证返回 ID、写接口尚未完成真实平台验收的限制仍然存在。
