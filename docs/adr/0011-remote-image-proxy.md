# ADR-0011 远程图片经主进程代理加载

- 状态：已接受
- 日期：2026-10-15

## 背景

开发者头像、排行榜作品图标是网易 CDN 上的图片（如 `x19.fp.ps.netease.com`）。渲染进程的 CSP 只允许本地资源，安全基线也要求不加载任何远程内容。如果直接放开 `img-src https:`，页面就能向任意地址发请求，插件也能借图片地址把数据带出去。

## 决定

- 新增 `glaze-image://remote/?u=<地址>` 协议，由主进程处理；渲染进程只在 CSP 里多允许 `img-src glaze-image:`，不放开任何远程源。
- 主进程只代理 https 的网易图片域名（`.netease.com`、`.126.net`、`.127.net`、`.163.com`），不跟随重定向，只接受 `image/*`，单张最大 5 MB，超时 15 秒。
- 代理请求不带任何 Cookie（用 Node `fetch`，与网易会话完全分开）；内存缓存最近 300 张。
- 界面通过 `remoteImageUrl(url)` 生成地址；`@glaze/ui` 的 `Avatar` 在没有图片或加载失败时退回像素头像。

## 后果

- 页面看不到也不直接连接远程地址，域名白名单集中在 `@glaze/netease` 的 `isNeteaseImageUrl`。
- 网易换图片域名时需要改白名单。
- 缓存只在内存，重启后重新下载；以后需要离线显示时再加磁盘缓存。
