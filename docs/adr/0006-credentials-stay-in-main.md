# ADR-0006 凭据只存在于主进程

- 状态：已接受
- 日期：2026-10-15

## 背景

原项目中 Cookie 会随 GitHub 更新请求外发，密码与 Cookie 明文存储，部分日志输出 Cookie。

## 决定

- Cookie 和密码只存在于主进程的会话管理与保险箱模块，用 safeStorage（DPAPI）加密落盘。
- 渲染进程和插件只能按端点 ID 发起网易请求，由主进程附加会话。
- 网易请求与公共请求使用两个独立的 HTTP 客户端，公共客户端永远不带 Cookie。
- 日志统一脱敏。

## 后果

- 凭据外泄从"靠约定避免"变成"结构上做不到"。
- 所有网易接口必须登记在端点目录中，临时调试也要走端点定义。
- 数据库备份和导出需要排除凭据表。
