# ADR-0005 插件按信任等级隔离运行

- 状态：已接受
- 日期：2026-10-15

## 背景

允许第三方插件意味着要运行不受信任的代码，而应用持有网易账号凭据，可以修改作品和申请结算。

## 决定

插件分为 `builtin`、`theme`、`declarative`、`custom-ui` 四个等级。信任等级由安装来源决定。第三方逻辑运行在插件宿主进程（utilityProcess），界面要么由宿主按声明渲染，要么放进沙箱 iframe。所有能力通过带权限检查的 RPC 获取。按风险从低到高逐步开放。

## 后果

- 第三方插件崩溃或作恶时影响范围受限。
- 声明式界面限制了插件的表现力，但换来自动适配主题和更高的安全性。
- 插件宿主进程、桥接和权限确认界面增加了实现成本，因此放在 M5 分阶段完成。
