# ADR-0003 内置功能也通过插件 API 实现

- 状态：已接受
- 日期：2026-10-15

## 背景

要求模块化、排版自由，并允许第三方开发插件。如果内置功能直接调用内部模块，插件 API 的缺口只会在第三方使用时才暴露。

## 决定

宿主只提供窗口、导航、布局、主题、插件管理和核心服务。账号、作品、数据、收益、互动、消息、设置全部作为内置插件，只依赖 `@glaze/plugin-sdk`。

## 后果

- 插件 API 在自己开发功能时就得到验证。
- 内置插件和第三方插件在页面、导航、组件、布局上的能力一致。
- 内置插件需要的能力都必须先进入 SDK，前期开发节奏会稍慢。
- 内置插件拥有 `builtin` 信任等级，可以使用 `netease:account.manage` 等第三方不可用的权限。
