# ADR-0002 pnpm workspaces + Turborepo 单仓库

- 状态：已接受
- 日期：2026-10-15

## 背景

宿主、内核包、内置插件、主题、插件 SDK 需要一起开发，同时又要保持清晰的边界，SDK 将来要单独发布。

## 决定

使用单仓库：pnpm workspaces 管理包，Turborepo 编排构建、类型检查和测试并做缓存。

## 后果

- 跨包修改可以在一个提交里完成，契约变化立刻在所有使用方暴露。
- 包边界靠依赖规则和 CI 检查维持，而不是靠仓库隔离，需要在 `tools/` 中实现边界检查。
- `@glaze/plugin-sdk` 需要单独的发布流程，不能依赖仓库内的私有包。
