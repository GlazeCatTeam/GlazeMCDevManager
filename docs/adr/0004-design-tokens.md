# ADR-0004 三层设计令牌 + 主题包

- 状态：已接受
- 日期：2026-10-15

## 背景

需要支持多套主题（首套为 Ore UI），并且第三方插件的界面要自动适配所有主题。Ore UI 与 Fluent 这类主题在圆角、描边、按钮厚度上差异很大。

## 决定

令牌分为基础值、语义令牌、组件令牌三层。组件只读语义和组件令牌。主题以主题包（`theme.json` + 图标 + 字体）分发，支持继承和变体，运行时转成 CSS 变量。主题不包含代码。

## 后果

- 新增主题不改组件代码；主题包可以安全地在用户之间分享。
- 组件开发必须遵守"不写死样式值"的约束，需要检查工具配合。
- 少数令牌无法表达的差异通过受限的 `overrides.css` 处理，需控制其使用范围。
