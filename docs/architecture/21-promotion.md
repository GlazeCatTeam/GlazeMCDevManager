# 活动推广

2026-10-16 新增独立内置插件 `glaze.promotion`。侧栏入口紧接收益管理，路由为 `glaze.promotion/promotion`，支持插件启停与启动时恢复上次页面。

## 页面与行为

活动介绍、规则和赛道说明使用 `ActivityContent` 显示平台 HTML：复用 SDK 的 HTML 白名单清理与图片代理，保留段落、换行、强调、列表，移除平台内联样式和字体颜色/尺寸，使其跟随当前主题。链接只保留说明文字，不导航应用窗口。卡片摘要与行内分区提示转换为纯文本，段落边界保留空格，避免显示 `<p>`、`<br>` 或将相邻段落连在一起。

- 作品活动：平台分页列表、活动规则与时间、赛道切换、候选作品筛选、单作品报名介绍及图片/视频上传、报名记录与审核状态。
- 折扣特卖：当前活动与规则、赛道切换、多作品选择、平台折扣范围、可选分区、报名确认和取消参与确认。平台百分比原值展示，不推算未验证的折后价。已通过/未通过记录不显示取消入口。
- PE 轮播图申请：改为「选择作品与日期 → 准备宣传内容 → 核对提交」三步，作品直接搜索点选，日期卡片展示资格与原因；选图后拖动/缩放裁剪到 940 × 450；四项文案逐项填写，提纲只填入空白项；核对页明确点击后提交，不再重复弹出相同确认表单。申请记录独立全宽展示，可查看、修改或复用内容。

保持现有 Ore UI、CSS Modules 和三层主题令牌，使用共享页面标题、面板、按钮、分段选择、提示和分页控件。作品活动与特卖双栏面板固定 680px 高；轮播工作区高度随窗口变化（最大 680px），不随内容变化，标题、步骤与底部操作常驻，只有中间内容滚动。支持 Ore 深浅色与 Fluent。活动图片复用 `glaze-image:` 代理；平台文本不会作为 HTML 执行。

轮播草稿在当前账号的申请记录页与外层活动标签之间保留，返回上一步不会丢失字段；退出应用前通过现有未保存提示保护。草稿保存在当前页面内存，不宣称跨进程保存；账号切换会清空。替换未提交草稿必须明确确认，复用申请只带回作品、宣传图和文案，必须重新选日期。提交失败保留草稿，结果不明确时停止重复提交；错误提示固定在底部操作上方。图片替换失败保留旧图，图片预览失败可单独重载，不重复上传。

账号变化会卸载旧表单，候选赛道与分页通过 key 隔离请求。查询失败明确提示，保留的旧数据标记为上次结果，阻止基于失败查询提交。写操作要求确认，主进程验证当前账号；网络或解析导致结果不确定时禁用重复提交并提示核对记录，不自动重试。

已结束活动按正常业务状态展示“活动已结束”，保留介绍、规则和现有固定面板，隐藏报名表单、素材上传及提交入口。列表时间已表明结束时不挂载赛道报名查询；时间尚未同步但平台明确返回业务原因“活动已结束”时，也用同一空状态替代错误提示和重试按钮。网络故障及其他业务错误继续正常提示，不一概隐藏。

列表每页 10 条，`start = page * 10`。轮播申请记录固定 `platform=pe&type=apply`。新申请发送 `/promotion-banner/apply/`，修改发送 `/promotion-banner/apply/modify/{applicationId}`；固定字段为 `position_id=6`、`item_category=pe`、`special_promotion=false`、`start_time_zone=-8`、`is_check=true`。日期保留平台 Unix 秒键，界面按 Asia/Shanghai 展示。报名保留图片/视频签名回执，上传复用现有本地文件校验与网易上传管线。

报名提交前重新校验候选集合，折扣报名还会重读当前活动、折扣范围和截止日期。轮播新申请重查可申请日期。修改轮播的最终状态合法性由平台裁决，当前没有原子版本条件更新协议。

## 轮播选择与搜索的连续操作优化（2026-10-16）
