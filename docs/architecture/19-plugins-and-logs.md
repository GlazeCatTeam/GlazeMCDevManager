# 插件管理与运行日志

## 本轮实装范围

- 插件列表读取构建时收集的真实 `glaze-plugin.json` 清单及用户安装的主题，显示名称、版本、描述、启用状态和加载错误。
- 账号、首页、设置和内置主题为必需组件；其他内置模块可启停，状态存入 SQLite `settings(app, plugins.enabled)`。
- 停用模块的导航隐藏，页面入口被阻止加载；可选页面按需导入。作品后台预热的启停随独立的作品性能改动一并集成。
- 已停用模块的写操作在主进程拒绝。共享读取能力属于宿主数据服务，例如分析页仍可读取作品列表，首页仍可读取数据概览。
- 启动页面属于停用模块时回到首页。页面加载错误由局部错误边界显示，保留导航和设置。
- 按 [04 插件系统](04-plugin-system.md) 的分级顺序，本地安装仅开放无代码、无权限的主题包。代码型第三方插件、进程宿主、声明式组件和沙箱 iframe 尚未开放，不会把安装它们伪装成成功。

## 本地主题包

支持 `.glazeplugin` 或 `.zip`，包内包含 `glaze-plugin.json` 和一个主题 JSON。允许整体置于单个根文件夹，可附带 README/许可文本。原生文件选择后先显示名称、版本和安装确认，确认前不落盘。最大压缩包 2 MB，单文件解压上限 1 MB，总解压上限 2 MB，最多 32 个 ZIP 条目。

最小清单：

```json
{
  "id": "example.ocean",
  "name": "海洋主题",
  "version": "1.0.0",
  "description": "蓝色背景的主题",
  "engines": { "glaze": "^0.1.0" },
  "permissions": [],
  "contributes": {
    "themes": [{ "id": "example.ocean", "path": "theme.json" }]
  }
}
```

对应 `theme.json`：

```json
{
  "id": "example.ocean",
  "defaultVariant": "dark",
  "tokens": {
    "semantic": { "surface.app": "#234567" }
  }
}
```

缺省令牌继承完整的 Ore UI 基础，可用 `variants.light`、`variants.dark` 提供变体。只声明深色的主题不能选择浅色或跟随系统；支持两种模式后可跟随系统。

安装器校验 ZIP CRC、边界、文件数量、压缩方式和路径；拒绝越界路径、链接条目、加密、多卷、ZIP64、代码入口、权限声明及内置 ID 覆盖。主题值不能加载 URL、插入 CSS 规则或包含脚本表达式；令牌引用检查缺失、循环、深度和展开大小。

内容不按 ZIP 路径解压，仅将校验后的原始清单和主题 JSON 保存到 `userData/plugins/<id>/<version>/package.json`。先写随机暂存目录，再原子发布版本目录，失败不会覆盖旧版本。目录访问拒绝符号链接。同版本和降级安装被拒绝，更高版本保留启停状态。旧版本文件保留，当前管理界面不提供卸载和回滚入口。

安装后的已启用主题立即出现在外观设置中，选择结果跨重启恢复。当前使用的主题不能直接停用；升级若不支持当前颜色模式，需要先切换到内置主题。损坏的本地主题显示不可用，不阻止内置模块启动。

## 日志

- 日志存于 `userData/logs/`，按 UTC 日期写入 JSONL，界面时间按本地时区显示。
- 每个文件不超过约 2 MB，每天最多保留当前文件和两个轮转文件，保留最近 14 个 UTC 日期。
- 记录应用启动、会话状态变化、插件安装/启停、设置或业务写操作成功、RPC 失败、界面脚本错误和进程异常。
- RPC 仅记录已知方法名和结果类别，不记录参数、账号 Cookie、响应正文或原始异常文本。消息进入文件前再次脱敏 Cookie、Authorization、NTES_SESS、密码、token 等内容，移除控制字符和 URL；读取及导出时再次脱敏。
- 日志页支持信息/警告/错误筛选、自动刷新和手动刷新。当前级别最多显示最近 500 条，截断时明确提示。
- 导出通过原生保存对话框输出当前级别最近 500 条的文本快照；取消不报成功。打开文件夹使用宿主固定日志目录。
- 清除需要确认，删除所有日期和级别的应用日志；只处理固定命名的日志文件，目录中的其他文件不受影响。
- 磁盘写入失败不会中断业务，但日志页会报告故障；损坏记录、导出失败和目录打开失败不会显示为成功。

## 接口与验证

`plugins.list/setEnabled/pickInstall/install`、`logs.list/export/clear/openFolder` 和 `app.reportRendererError` 均限制主应用窗口的主框架调用，不向 MCP 暴露。界面错误只接受固定分类，不接受原始报错文本。`plugins.changed` 同步宿主注册表，`logs.changed` 触发日志页合并刷新。

- `node tools/test-plugins-logs.mjs`：ZIP 校验、主题内容限制与展开限制、插件启停和安装重启、必需模块保护、损坏/链接包隔离、真实日志脱敏、导出、清除、轮转及保留期。
- `pnpm build` 后运行 `node tools/test-plugins-logs-electron.mjs [Playwright 模块 URL]`：真实桌面、临时用户目录和离线网络；覆盖导航启停、写入阻止、安装确认/取消、主题应用及重启、日志筛选/导出/清除/取消、打开目录和敏感数据隔离。原生选择/保存对话框由测试夹具提供路径。
- 外观、通用和作品回归测试；设置、SDK、桌面类型检查；修改文件的 Biome 检查和桌面构建。
