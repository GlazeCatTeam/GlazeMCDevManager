# MCP 业务直连接入

更新日期：2026-10-16。当前实现按用户要求移除了 AI 草稿工作流与逐次确认。AI 在授权范围内直接查询、编辑和执行业务操作。

## 连接与授权

设置 → AI 接入：填写端口并启用服务，默认地址为 `http://127.0.0.1:17839/mcp`。使用标准 Streamable HTTP；Codex、Claude Code、Cursor 等客户端填写应用显示的 URL 即可。端口持久保存，改端口被占用时保留原监听与连接。

首次连接后在应用内选择账号、默认账号与权限。授权窗口提供「全部业务权限」和「仅基础查询」快捷选项；默认只勾选基础读取权限，收益与写权限不默认选中。旧授权不会自动扩大。新会话不会根据自报名称继承授权。

无需生成邀请、启动桥进程、创建 AI 草稿或逐次确认保存。设置页显示操作结果与审计记录，已移除 AI 草稿列表和编辑入口。原内部快照数据在启动时清理；仅保留仍被上传材料或未解决操作引用的后台快照。

## 直接修改作品

`works_editor` 读取当前字段；`works_save` 一次调用即可完成指定字段的修改和保存。例如：

```json
{
  "itemId": "4686664860310207622",
  "patch": { "item_name": "MCP测试作品" },
  "base": { "item_name": "旧名称" },
  "idempotencyKey": "rename-unique-request"
}
```

`base` 可选，用于核对 AI 读取时的原值。宿主仍会在实际保存前复核平台数据和作品状态。`patch` 支持现有编辑器全部可写分区字段，包括基本信息、定价、详情、资源、图片、视频、PC 同步、更新与上架设置；只读平台字段不可伪造。普通保存默认不提审；`submitReview: true` 需要提审权限。

`works_create` 直接接收 `fields`；`works_submit_review` 直接接收作品 ID。新建未得到可靠作品 ID 时保留 `created_id_unresolved` 状态，不猜测 ID，不自动提审。

`works_upload` 直接导入并上传材料，返回 `assetId`。指定目录 ID 和相对路径时读取已授权目录，否则打开文件选择器。保存字段使用 `{ "$asset": "材料ID", "as": "receipt" }` 或 `url/name/size` 引用；富文本支持 `glaze-asset:材料ID`。材料严格绑定客户端、账号和作品，签名回执始终只在宿主内部使用。

## 业务能力范围

| 模块 | MCP 能力 |
|---|---|
| 作品查询 | 列表、分页、名称/ID 搜索、详情、编辑字段、选项、审核反馈、前置与关联搜索 |
| 作品编辑 | 直接保存全部可写字段、新建、上传材料、提审 |
| 作品状态 | 撤回审核、发布、预约/取消上线、提交/取消自测、删除、调价；要求准确 ID 与预期状态 |
| 推广 | 活动、赛道、日期、报名、折扣、轮播图申请查询；报名/取消折扣、上传推广材料、提交/修改轮播图申请 |
| 玩家互动 | 评论与反馈查询、回复、反馈日志读取 |
| 系统消息 | 列表、未读数量、读取并标记已读、全部已读、指定消息删除 |
| 数据收益 | 概览、日度/月度分析、周期/实时收益、结算列表/详情/估算 |
| 首页与应用 | 开发者等级、排行榜/分页/封面、账号基本信息 |

`promotion_upload` 上传推广材料，`promotion_join` 接受 `imageAssetIds` / `videoAssetIds`，`promotion_saveBanner` 接受 `imageAssetId`。宿主把经过归属和用途验证的材料替换为平台回执，禁止客户端伪造签名。

账号登录、Cookie/密码、客户端授权、插件安装、系统设置仍由应用管理，不提供任意 RPC 转发。评论和反馈回复工具只应在用户要求发送回复时调用。实现这些能力不代表自动执行删除、发布或向玩家发送消息。

## 执行与可靠性

- 工具拥有显式参数 Schema，拒绝未知字段。绑定授权账号，不跟随界面账号切换。每次执行前及实际发出平台请求前复核账号、权限与插件状态。
- 写请求提供 `idempotencyKey`；按客户端、账号和方法隔离。相同请求复用结果，不重复发送；相同键换内容时报错。
- 后台操作状态先加密刷盘再写入平台，返回结构化结果和操作 ID。失败或结果未知带 `isError`；`unknown` 禁止自动重试，须核对平台结果。
- 同一作品写入串行；其他业务按账号和模块串行。已有未解决写入结果时阻止继续覆盖。
- 不再对外提供 `works_draft_*`、`works_asset_*`、`mcp.editDraft` 和 `mcp.decide`。内部快照执行器保留以复用材料校验、版本比较与失败恢复；完成的无材料快照立即清理。
- 本机只监听 `127.0.0.1`，校验 Host/Origin；最多 32 个会话，空闲 30 分钟释放会话，输入最多 3MB，每客户端每分钟最多 60 次业务调用。

## 验证和边界

协议与服务测试覆盖 HTTP 协商、授权、直接保存、快照清理、全部业务工具发现、上传归属、参数校验、账号隔离、幂等、并发与未知结果。宿主适配测试检查真实请求构造与发送前授权回调。Electron 和界面测试使用临时账号或桩，验证端口、权限、无草稿界面及重启恢复；既有作品适配器回归继续运行。

真实网易作品改名及保存回读已验证。新增发布、删除、玩家回复、消息删除和推广写入只做隔离测试，不对真实账号执行试验性写入。平台未提供原子条件写入，最后复核与提交间仍存在短暂竞态。
