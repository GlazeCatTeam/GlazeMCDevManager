# 12 路线图

每个里程碑都以一个可运行、可验证的闭环结束。

| 里程碑 | 内容 | 验收标准 |
|---|---|---|
| **M0 工程骨架** | 单仓库、Electron 窗口、自定义标题栏、Biome、TypeScript、Vitest、CI | `pnpm dev` 打开空窗口；`pnpm build` 产出安装包；CI 绿色 |
| **M1 内核** | RPC 契约与路由、插件注册表（只加载内置插件）、主题引擎 + Ore UI、布局引擎骨架、SQLite 与迁移、凭据保险箱 | 内置插件能注册一个页面和组件并显示；切换亮暗变体生效；布局能保存与恢复默认 |
| **M2 账号** | 会话管理、邮箱与 Cookie 登录协议、启动路由判定、登录页、过期页、账号管理页 | 真实账号能登录、切换（失败回滚）、过期后进入重新登录页；网络错误不误判过期 |
| **M3 业务模块** | 首页、作品、数据分析、收益结算、反馈与评论、消息，全部以插件实现 | 覆盖原项目核心功能；收益查询失败显示不完整提示，不显示为零 |
| **M4 体验完善** | Fluent 深色主题、布局编辑模式、导航自定义、设置页、应用更新 | 两套主题切换无遗漏；用户能自由调整账号页和首页布局 |
| **M5 开放插件** | 主题插件安装 → 声明式组件插件 → 自定义界面插件；权限确认与审计视图；插件开发文档与示例 | 第三方能按文档做出一个读取作品数据的看板插件，并在权限内运行 |

## 当前状态

- 已完成：架构设计、仓库结构与基础文件夹、内置插件清单、两套主题的令牌初稿、登录与账号页设计稿。
- 进行中：M0。已完成 git 初始化、依赖安装和第一个 Electron 窗口；待做自定义标题栏、Vitest、安装包构建和 CI。
